## Red flags

- **onboarding-name-light / onboarding-welcome-light — "wrong balance: floaty spacing, no breathing room" (inverted).** Measured empty bands: name has 271px above the mascot and 257px between the input and "continue"; welcome has 208px above Pip and **206px below the sign-in link**, i.e. its primary CTA floats mid-screen while every other step in the same flow anchors at y784. settings-subscription has a 212px band between the feature list and its CTA. On-grid, but not composed.
- **Codebase-wide — "default framework values left standing" (radius, not spacing).** 26 of 44 non-pill corner radii are untouched Tailwind defaults (`rounded-2xl` 16px ×21, `rounded-xl` 12px ×3, `rounded-3xl` 24px ×2) sitting next to the project's own `--radius-card` (20px) and a `--radius-field` (14px) used exactly once. Visible on settings-light: 20px help card above 16px rows.
- Checked and **not** found: **generic gradients** (enumerated every one — three functional scroll masks, one lock scrim, the brand-sanctioned mascot radial; no purple, no unmotivated fill); **default spacing** (six spacing steps, zero 12px/20px); **too many colours/fonts** (3 families, 3 weights, 6 sizes, neutral ≥55% on 21/21 screens); **card-grid filler** (the timeline's stacked cards carry distinct content in a deliberate two-tier featured/compact treatment); **generic copy** (grep for unlock / powerful / journey / built for / everything you need returns only a post-purchase "welcome to pip+"); **glassmorphism** — I pixel-sampled the thread header band: bleed-through under the `bg-bg/90 backdrop-blur-md` bar is ≤2/255 in light and ≤11/255 in dark, so it reads as a solid warm bar, and the one real `blur-[3px]` is doing semantic work on the locked day.

## Top 3 fixes (highest leverage first)

1. **Compose the vertical, don't just grid it.** Put `welcome/page.tsx` on `StepShell` so its CTA anchors with the rest of the flow (kills the 206px dead band), and give `StepShell` a `justify-start pt-16` content block instead of `justify-center` so onboarding-name stops leaving 63% of the viewport empty. Same move on settings-subscription: drop `mt-auto pt-8` for a sticky footer so the 212px gap closes.
2. **Enforce the radius ladder you already wrote.** Replace all 21 `rounded-2xl`, 3 `rounded-xl` and 2 `rounded-3xl` with `rounded-card` / `rounded-field` / `rounded-bubble`, and add `--radius-*: initial` alongside the existing `--text-*: initial` in `@theme inline` so Tailwind's defaults stop compiling — the same trick that made the type ramp uncheatable. Start with settings-light, where a 20px card sits 8px above five 16px rows.
3. **Give meditation-pause one primary and a readable ring.** Demote the pattern toggle to a small text link under the pacer (or move it behind the close-adjacent corner) so "i feel ready" is the only pill; raise `BreathRing`'s track from honey@0.35 (1.20:1 on cream) to `--line` at full opacity so the arc reads as progress rather than a stray dash. While there, rename "4-4-4-4 Box" to Pip's voice ("even in, even out").
