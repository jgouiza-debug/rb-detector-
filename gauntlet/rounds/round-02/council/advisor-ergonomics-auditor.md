## Red flags
- None found for: default/generic gradients (checked `globals.css` and all `.tsx` for `gradient` — only functional scroll-fade masks and one fade-to-background at the paywall lock line, `MemoryDetail.tsx:63`); default framework spacing (Tailwind's own type scale is deliberately zeroed, `globals.css:140`); too many colors/fonts (gate confirms 6/3/3); repeated card-grid filler (the timeline's stacked `CompactCard`s are a real chronological list of distinct days, not decorative filler); generic SaaS copy ("unlock," "journey," "powerful" — none found in any onboarding, chat, or paywall copy read); glassmorphism/blur used gratuitously (the two uses of blur — `Composer.tsx`'s `backdrop-blur-md` sticky footer and `MemoryDetail.tsx`'s locked-preview blur — are both functional: legibility over scrolling content, and an honest "the day is there, it just isn't readable yet" lock state).
- `thread-light.jpg` / `thread-crisis-light.jpg`, every chat bubble (`components/chat/Bubble.tsx`): a screen-reader-invisible interaction problem the gate cannot catch — 35–46 "buttons" per screen whose accessible name is the message text itself and whose action (reveal a timestamp) is announced nowhere. Not one of the rubric's named flags, but squarely the "control names that tell a screen-reader user nothing" the persona is scoped to catch.
- `meditation-pause-light.jpg`: four live decisions on the one screen the brief says should feel like "everything slows down" (close / ready / switch pattern / pause).

## Top 3 fixes (highest leverage first)
1. **De-button the message bubbles.** In `Bubble.tsx`, either drop the `<button>` wrapper for a plain `<div>` with a small always-visible or on-long-press timestamp, or keep it interactive but give it a real accessible name (`aria-label="show time sent"`) and announce the reveal (`aria-live` or `aria-expanded`). As shipped, a VoiceOver/TalkBack user gets 30–40 unlabeled "buttons" per screen with no idea what they do.
2. **Separate the two icon targets in the top bar.** `ThreadTopBar.tsx`/`TimelineTopBar` put "your story" and "settings" 4px apart. Give them at least 16px of gap or move Settings behind a single "more" affordance — a stray thumb currently swaps a read/browse action for an entirely different destination with zero confirmation.
3. **Cut the pause screen back to one decision.** Move "switch rhythm" (4-4-4-4 Box) into a pre-session choice or fold it under a low-emphasis "options" disclosure, so the in-session screen is just breathe / done — matching the brief's own "slow everything down" instruction for this exact screen.
