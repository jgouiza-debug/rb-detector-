## Top 3 fixes (highest leverage first)

1. **Timeline header hierarchy tightening (B1, +1 point potential)**: The timeline-light full-page view shows competing visual weights between "your story" (h2, ~28px Fredoka, text-fg), "this week's flow" label (14px, text-fg-soft), and the seven mood dots (24px, saturated colors). The hue richness of dots (sunlight, blush, sky) can draw the eye before hierarchy settles. **Fix**: reduce mood dot background saturation by 10–15% (e.g., `opacity-80` on dot backgrounds), or set "this week's flow" label to font-weight: 400 (not 600). This sharpens the entry point to "your story" without losing the mood trend signal. **Evidence**: timeline-light-full.jpg shows the hierarchy is mostly correct but could be crisper.

2. **Gentle spring easing on primary interactions (B4, +0.5 point refinement)**: Current motion uses fade and scale with default ease-out (linear descent), which is calm but slightly mechanical. **Fix**: add cubic-bezier spring easing (e.g., `cubic-bezier(0.34, 1.56, 0.64, 1)`) to 50ms button press feedback and card reveal animations. This adds imperceptible bounce (feels responsive without raising heart rate). **Evidence**: compose send button on thread-light should have subtle spring-back effect; meditation ring could use spring-scale on entry. Breath is already smooth (intentional long cycle); this fix applies to UI buttons.

3. **Breathing skeleton state visibility confirmation (B3, +0.5 point refinement)**: Thread screenshots don't visibly show skeleton cards while Pip is composing a response (code shows Skeleton components exist; they may be hidden by optimistic updates or rapid AI response). **Fix**: Add visible skeleton shimmer (light → slightly darker → light cycle, 1.5s) for the first 300ms of Pip's response to signal "thinking" (particularly on first message after send). This adds micro-feedback without adding latency or spinners. **Evidence**: TypingDots exist but brief skeleton would reinforce "Pip is writing" state. Current optimistic updates are fast enough that shimmer may not be necessary, so this is a refinement only.

## Notes for peers

- **All Tier A gates pass cleanly**: 0 axe violations, 0 contrast failures, perfect focus states, all targets ≥44px, 95.2% grid compliance, zero console errors. This is a production-ready baseline.
- **Crisis response is exemplary**: The CrisisCard component and scripted response ("i'm not a substitute... please reach out... i'm still right here") hits the exact tone the brand guidelines call for ("warm plus honesty plus real resources"). No competitor in the companion app space matches this warmth-to-safety ratio.
- **Memory card as core UX payoff works**: The Fraunces serif shift, the date prominence, and the reflection in the user's own voice (not Pip's synthesis, which would be clinical) makes the timeline feel like a keepsake, not a data dump. This is the differentiator.
- **Mascot restraint is paid off**: Pip appears in the right places (avatar on every message, small presence on empty states, signature-sized on memory cards) but never over-merchandised. The expressions (listening, happy, thinking, cozy) are readable at 24px and add warmth without cuteness-creep.
- **Onboarding framing sets tone**: "what's on your mind these days?" + "pick any that fit, or none" + "so i can gently check in" establishes that Pip is permission-giving, not prescriptive. This carries through the entire product.
- **Paywall tone is rare in this category**: "keep your whole story" + "cancel anytime · export stays free" reads like a friend explaining what more you'd get, not a growth-team extraction. No dark patterns detected.
