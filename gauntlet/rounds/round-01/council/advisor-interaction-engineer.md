## Top 3 fixes (highest leverage first)
1. **Settings grouping** — Group the 6 settings into 3 sections (Account / Preferences / Legal & Data) with section headers. This reduces cognitive load on the settings screen and makes it feel more structured. Currently 6 equal-weight items compete, especially the linear hierarchy (get help first, but it's not a setting). Recommend: Help card stays prominent at top (different background color), then Account (email, sign out), Preferences (rhythm, notifications), Legal (data, privacy). Estimated effort: low (just CSS grid + headers), impact: improves C1 (cognitive load) to 7/7.

2. **Warmth in limits communication** — Timeline "7-day window" pill feels literal. Change to "seven days saved" or "your recent keepsakes" (or similar) to match the brand warmth. Also, the settings description "export or delete everything" could add a line: "your words, always yours" to reinforce control + warmth. Estimated effort: very low (copy only), impact: improves C2 (brand resonance) to 7/7 and C4 (paywall tone) to 5/5.

3. **First-week celebration** — Add a micro-moment when the user completes their first full week or first memory synthesis (e.g., Pip bounces + "look at your week 🌱" toast, 3s animation then fade). Currently the memory timeline is functional but lacks the emotional payoff that the brand promises ("every nice moment earns its place"). This would reinforce the "warm companion" feel and give users a reason to revisit the app. Estimated effort: medium (new component + animation + API hook), impact: improves B5 (originality, point of view) and C3 (delight) to 7/7.

## Notes for peers
- **Micro-interactions are excellent**: 150ms transitions, spring/soft easing, press states, optimistic sends, typing indicators, and skeleton states all work together to create a responsive, tactile feel. The app never throws spinners at the user — every action confirms itself immediately. This is the gold standard for B3 and B4.
- **Reduced-motion handling is thoughtful**: The prefers-reduced-motion media query disables keyframes, but the breathing pacer (most animation-heavy screen) falls back to a 200ms discrete scale animation instead of appearing dead. This respects the user preference without sacrificing responsiveness. The motion-scale variable on the pause screen (1.6×) is clever — it slows animations during meditation without code changes.
- **Optimistic updates shine**: The threadStore.ts `send` function creates the message immediately with `status: "pending"` and reduced opacity (not disabled). This gives users instant feedback that the message was sent, even if the AI reply takes seconds. No jank, no retry loops.
- **Hierarchy risk on timeline**: The week-flow dots and mood filter pills are at the same visual weight. A user new to the app might not immediately understand the dots are a mini timeline, not just decoration. Consider adding a small label ("this week's flow") or lightening the mood filter pills to draw more attention to the dots.
- **Crisis screen is warm**: The thread-crisis-light.jpg shows genuine emotional intelligence. Pip says "i'm not going anywhere" before listing resources, and resources are presented as options (with icons and regions), not as a clinical referral. This matches the brand promise of "warm, never clinical." Verify this screen is tested with real users in crisis to ensure the tone doesn't feel patronizing.
