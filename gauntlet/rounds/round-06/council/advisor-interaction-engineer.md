## Red flags
- `components/chat/VoiceSheet.tsx:86-90` — "Glassmorphism/blur/animation used because it's possible" flag: the listening-state waveform bars (`animate-voicebar`) run a fixed, staggered CSS loop regardless of actual mic input; `hooks/useDictation.ts` performs no audio-level analysis at all, so the bars simulate a live waveform without ever reflecting one. Not a hard blocker (it doesn't mislead about function — dictation itself works — but it visually promises live audio feedback it doesn't deliver).
- Checked and NOT found: default/generic gradients (only the brand-permitted sunlight→honey glow in `PipMascot.tsx:38-46` and functional mask/fade gradients in `globals.css`/`MemoryDetail.tsx:63`); untouched Tailwind spacing defaults (type ramp and spacing tokens are hand-authored and structurally locked, `globals.css:144-159`); repeated card-grid filler (timeline deliberately varies card shape by recency); generic SaaS copy (audited onboarding, thread, timeline, paywall, settings, help — all lowercase, first-person, product-specific); glassmorphism (no `backdrop-blur` found outside the functional, purposeful blur on locked timeline content).

## Top 3 fixes (highest leverage first)
1. Give `PhotoBubble` the same `animate-bubble-in`/`fresh` treatment `Bubble` gets (`components/chat/PhotoBubble.tsx`) — right now a sent photo is the one message type that doesn't confirm itself with the arrival motion every text bubble gets; it's a one-line prop plumb-through from `MessageList.tsx:41-42`.
2. Tie `VoiceSheet`'s waveform bars to real input, or drop the false-live framing — either read `AnalyserNode` levels from `getUserMedia` (small lift, real payoff) or replace the 7 animated bars with a single calmer "listening" pulse that doesn't imply per-syllable reactivity it doesn't have.
3. Add `transition-colors duration-150` to `ThemeToggle.tsx:48` and `PatternToggle.tsx:11` so every selectable pill in the app (not just `Chip`) changes state with the same softness — currently two of these snap instantly while the rest ease.
