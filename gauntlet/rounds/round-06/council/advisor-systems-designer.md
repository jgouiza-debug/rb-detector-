## Red flags

- `timeline-dark-full`: mood chips — **too many colours / no 70-20-10 discipline in dark**. `moodTokens` (`lib/theme/tokens.ts:44-51`) is theme-agnostic, so `mixed` (`#FFF3D1`) and `heavy` (`#D6CCBC`) render as near-white chips on `#26231F` cards, brighter than the `bright` chip (`#FFDE7A`) they sit above. The neutral moods become the loudest thing on the screen. Dark mode is a second design everywhere else in this build (surfaces, Pip bubble, rings, glow) — the mood scale is the one token family that was left un-remapped.
- `settings-light` / `settings-dark`: HelpNowCard vs SettingRow — **untouched Tailwind defaults left standing**. `globals.css` wipes the type namespace (`--text-*: initial`) but not the radius namespace, so `rounded-2xl` (16px, 17 uses), `rounded-xl` (12px) and `rounded-3xl` (24px) ship next to the declared `field`/`bubble`/`card` rungs. On this one screen a 20px card sits directly above 16px rows, with 40px vs 36px icon chips.

Checked and **not** found: default or unmotivated gradients (7 `gradient` hits, all masks, the brand-sanctioned mascot radial, or one transparent→bg scrim); default framework spacing (94.6% on 8pt, zero `p-3`/`px-5`/`gap-3`, the only 12px is a documented 44px-hit-area overhang); too many fonts (3, structurally enforced); repeated card-grid filler (the EARLIER list is chronological and demoted from the hero cards, not decoration); generic copy (every CTA and heading read; none could belong to another app); glassmorphism (exactly one `blur-[3px]` in the codebase, on the locked memory, zero `backdrop-blur`); floaty spacing (the 144px void the gate flags on `meditation-pause` is a `justify-center` takeover with ~140px above the ring and ~166px below the last control — balanced centering, not a dead bottom).

## Top 3 fixes (highest leverage first)

1. **Close the radius namespace the same way the type namespace was closed.** Add `--radius-*: initial;` next to `--text-*: initial;` in the `@theme inline` block, then remap the 22 off-ladder uses: `SettingRow.tsx:20` `rounded-2xl` → `rounded-card` (kills the 20px/16px mismatch against HelpNowCard on `settings-light`), the onboarding name input and rhythm rows → `rounded-field`, `Composer.tsx:126` `rounded-3xl` → `rounded-field`, `Skeleton.tsx` `rounded-xl` → `rounded-field`, and every `rounded-full` on a non-circular element → `rounded-pill`. That drops 8 shipped radii to 4 and makes drift impossible without editing `globals.css`, exactly as it already is for type.
2. **Give `moodTokens` a dark half.** Add `bgDark`/`fgDark` (or a `[data-theme="dark"]` CSS-var pair) so `mixed` lands near `#3A3229` with `night-text` and `heavy` near `#4A443B` with `night-text`, while `bright`/`calm`/`tender` keep their hue at reduced luminance. Today the two colours that mean "nothing in particular" are the brightest pixels on `timeline-dark-full` after the yellow, which inverts the emphasis the light theme gets right.
3. **Unify the secondary-action treatment and the mood label.** One `Button variant="soft"` for every secondary (currently: outlined white on `help-light`, `pip-bubble` fill on `settings-subscription-light`, surface pill on `meditation-pause-light`), and make `MemoryDetail.tsx:93` render `mood.label` rather than the model's `moodLabel`, so `memory-card-light` says "bright" like the timeline does instead of "Bright & warm" — one lowercase voice, one chip.
