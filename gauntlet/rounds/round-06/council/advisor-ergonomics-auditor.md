## Red flags
- Checked: default/generic gradients — none found. Only gradient in the app is the sanctioned sunlight→honey glow behind Pip (`onboarding-welcome-light.jpg`, `meditation-pause-light.jpg`).
- Checked: default framework spacing — none found; gate shows 94.6% on the 8pt grid with the remainder inside components (4pt allowance).
- Checked: too many colors / muddy 70/20/10 — none found; gate's palette proxy passes 23/23 screens, neutral family dominant on every screen I opened.
- Checked: repeated card-grid filler — none found. `timeline-light-full.jpg` has multiple cards but each carries distinct date/mood/reflection content, not identical filler shapes.
- Checked: generic SaaS copy — none found; copy is consistently specific and lowercase per brand voice.
- Checked: glassmorphism/blur used because it's possible — the one blur (`memory-locked-paywall-light.jpg`, locked card) is purposeful (shows shape without content, per the code comment in `MemoryDetail.tsx`), not decorative.
- Checked: wrong balance (cramped/floaty) — none found; screenshots show generous, consistent breathing room.
- **Not on the rubric list but a genuine a11y red flag**: `components/timeline/TimelineView.tsx:116-131` — `role="tablist"`/`role="tab"` on the mood filter with no keyboard-pattern implementation (screen + element: timeline, "filter by mood" chip row, only visible after tapping "find a day").
- **Not on the rubric list but a genuine a11y red flag**: `components/pause/BreathingPacer.tsx:69-70` — `aria-live="polite"` wrapped around a mutating `<h1>` on the meditation-pause screen, firing every breath phase for the whole session.

## Top 3 fixes (highest leverage first)
1. **Fix the meditation-pause live region.** `components/pause/BreathingPacer.tsx:69-70`: move `aria-live="polite"` off the `<h1>{state.phaseName}…</h1>` and onto a separate, visually-hidden status node that only announces the phase name at a coarser cadence (or not at all — the ring + haptics already carry the beat non-visually). As written it turns the calmest screen into the chattiest one for a screen-reader user.
2. **Un-mislabel the mood filter.** `components/timeline/TimelineView.tsx:116-131`: swap `role="tablist"/"tab"` for the existing `Chip` component (`role="radio"` in a `role="radiogroup"`, since only one mood is active at a time) so the announced role matches the actual keyboard behavior, or implement the real APG tab pattern (`aria-controls`, roving tabindex, arrow keys) if `tab` is kept.
3. **Keep Fraunces to the three sanctioned surfaces.** `components/pause/BreathingPacer.tsx:70` sets "breathe in…" in `font-reading`. Move it to Nunito (the UI role) so the serif shift stays a signal reserved for memory cards and the timeline, per brand-guidelines §7 and the taste brief's "one screen, one texture" note on Stoic.

## Notes for peers
- Systems Designer: worth a second look at the `role="tab"` mood filter (component-reuse angle — `Chip` already exists and isn't used here) and the Fraunces-on-pause font-role slip; both are one-off patterns next to an otherwise very disciplined component set (`ResourceList`, `SettingRow`).
- Interaction Engineer: the `.breath-eased` reduced-motion exception in `globals.css:295-297` is a deliberate, well-commented choice (transitions ease to 1.2s rather than switching off) — worth confirming in your own pass whether the JS-driven scale interval is genuinely calm-paced under reduced motion, since the gate's "0 running animations" snapshot on meditation-pause may just have missed the interaction mid-transition.
- User & Brand Advocate: the crisis flow (`thread-crisis-light.jpg`, `help-light.jpg`) is the strongest brand-voice moment in the round — worth confirming the copy ("i'm a small app, not a person who can keep you safe right now — but there are people who can") reads the way the brand doc's crisis-tone example intends.
