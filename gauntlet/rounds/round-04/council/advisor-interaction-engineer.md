## Red flags
- Default/generic gradients: none found. Checked `globals.css` (only mask-image gradients for scroll-fade edges, and the two radial gradients on Pip's own body/glow) and every `.tsx` for `gradient`/`blur` (grep). The one linear gradient outside Pip (`MemoryDetail.tsx` L63) is transparent→bg, a fade mask, not a hue gradient.
- Default framework spacing: none found as a systemic pattern — gate's own 4px×114 off-grid count (A3.grid8) is a real but minor leak, not "everything the same padding."
- Too many colors/fonts: none found. Gate confirms 6 sizes / 3 families / 3 weights; I did not find an inline style bypassing the type scale in any file I read.
- Repeated card-grid filler: none found. `MemoryCard` (today/yesterday) vs `CompactCard` (earlier) are two deliberately different densities, not one shape stamped down the page.
- Generic copy: none found — see B5/C2 evidence.
- Glassmorphism/blur used because possible: `MemoryDetail.tsx` L53 blur is the only blur in the app and it is functional (soft-locks a real paywalled card), not decorative — checked and cleared.
- Wrong balance (type/spacing): none found beyond the B1 settings-screen flatness and the A3 4px leak already scored.

## Top 3 fixes (highest leverage first)
1. Wire `--motion-scale` (or an equivalent) into whatever actually renders motion on `/pause` — right now the "slow everything down" variable (globals.css L270-272) governs classes that don't appear on that screen, so the meditation calm-down is only real in the rAF-driven ring/scale, not in the CSS system built to express it (`BreathingPacer.tsx` L55).
2. Add a 150-200ms `transition-colors`/`transition-transform` to the "resonate" heart toggle in `MemoryDetail.tsx` (L85-86) — it's the one interactive element I found that changes state with zero animation, on the single most keepsake-y screen in the app.
3. Give the settings screen (`settings-light.jpg`) one visual break beyond the get-help banner — even a single elevated row or a size step on "subscription" would give B1 a second landing point instead of five identical rows.
