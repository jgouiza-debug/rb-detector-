## Red flags
- Default framework spacing: `gauntlet/rounds/round-00/gate-report.md` A3.grid8 — 344 instances of 12px, 336 of 6px, 218 of 10px, none on the 8pt grid. Traced to source in `components/chat/Bubble.tsx` (`px-4 py-2.5` = 10px), `MessageList.tsx` (`gap-1.5` = 6px) — untouched Tailwind half-steps standing in for the brand's stated "8/16/24/32/48" layout rhythm.
- Too many type sizes: A4.sizes — 10 distinct sizes (11–36px) against the taste-brief's "type ramp of six." No single shared scale is used across `Bubble`, `TimelineView`, `MemoryCard`, `BreathingPacer` — each picks its own `text-[Npx]`/`text-Nxl`.
- Generic/templated copy in the one place it must not be: every card in `timeline-light-full.jpg` — "Looking back, it felt like a lot to hold, and I got through it." — repeats verbatim across bright, calm, tender and heavy days. This is the mail-merge pattern the rubric's "generic copy" flag is aimed at, just in the AI-generated content layer rather than the UI copy layer.
- Sub-44px tappable chat bubbles: `components/chat/Bubble.tsx` — the entire message bubble is a button (tap-to-reveal-timestamp) at 40.6px measured height. Checked: settings rows, Button component (`h-11`/`h-12`/`h-14`), and nav icons all correctly use `.tap` (44px min) — this is isolated to the bubble component.
- Glassmorphism/blur used because possible: checked `Composer.tsx`'s `backdrop-blur-md` on the sticky footer — judged functional (keeps the input legible over scrolling messages, not decorative), so **not** flagged.
- Default/generic gradients: checked onboarding, splash, meditation screens for stray gradients — only the brand-sanctioned `sunlight → honey` glow behind Pip appears (`onboarding-welcome-*.jpg`). None found.

## Top 3 fixes (highest leverage first)
1. Fix the tap target on every chat bubble (`components/chat/Bubble.tsx`): give the `<button>` a `min-h-11` (44px) or wrap the tap-to-reveal behavior around a padded container instead of the bubble's own box — right now the single most-touched element in the whole app is systematically under the 44px floor the rest of the system respects.
2. Fix the timeline's horizontal overflow (`components/timeline/TimelineView.tsx` / `WeekFlow.tsx`): something inside `<main>` renders at 644px against a 390px viewport on both themes — find the un-clamped child (my read points at the mood-filter row or `WeekFlow`'s `ol`) and constrain it; this is the payoff screen the whole product is building toward, and it currently scrolls sideways on a phone.
3. De-template the daily synthesis closing line: the reflection generator (see the daily-synthesis prompt in `docs/handoff/03-design-spec.md §4.4`) is clearly landing on one fixed closing sentence regardless of the day's actual mood — vary or drop the "Looking back, it felt like a lot to hold, and I got through it" tail so a bright day doesn't read identically to a heavy one.
